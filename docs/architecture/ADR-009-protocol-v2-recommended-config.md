# ADR-009：协议 v2 与推荐配置枚举

> 状态：已接受
>
> 日期：2026-08-17

## 背景

产品把原“经典/常用角色”入口调整为“基础配置/推荐配置/自定义”，其中推荐配置为 5–10 人逐人数定义的精确牌组。9、10 人牌组不再等价于 v1 的 `COMMON_ROLES` 展开语义。线上枚举删除、重命名或改义属于 `ADR-007` 定义的破坏性变更。

## 决定

- HTTP 主路径、协议头、客户端能力、Bootstrap、Socket.IO 鉴权和实时消息统一升级为 `protocolVersion=2`；HTTP 主路径为 `/v2`。
- `PresetId` 只允许 `CLASSIC` 与 `RECOMMENDED`；`CUSTOM` 继续通过完整角色数组表达。
- v1 路径返回 `426 UPGRADE_REQUIRED`，v1 实时鉴权不再接受；邀请测试前不维护双协议消费者。
- `rulesVersion` 仍为 `CLASSIC_AVALON_V1`，因为推荐配置只选择现有合法角色牌组，不改变任务、知识、投票或胜负规则。
- 已持久化聚合只保存规范化角色数组，因此不需要数据库迁移；更新后的客户端仍可用原会话恢复未结束房间。

## 影响

- 所有客户端、服务端、负载/验收脚本、契约快照和运维探针必须原子切换到 v2。
- `COMMON_ROLES` 必须在 v2 Schema 中失败，避免静默沿用旧语义。
- 未来再次删除、改义或新增可能出现在服务端输出中的枚举值，继续按 `ADR-007` 执行协议版本评审。
