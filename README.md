# Avalon

面向线下聚会的阿瓦隆移动端主持与对局应用。每名玩家使用自己的手机查看私密身份和提交动作，云端服务器负责权威裁决，房主设备播放固定中文主持音频。

当前仓库处于开发前 P0 规范阶段，尚未创建 Expo 或服务端项目。MVP 通过邀请制测试分发，不面向 App Store/Google Play 公开发布。
